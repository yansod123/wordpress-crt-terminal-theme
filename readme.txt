A retro terminal-style WordPress theme with an interactive CRT companion.

== Description ==

CRT Terminal is a minimal, image-free WordPress theme inspired by terminal and command-line interfaces.
It features a customizable CRT companion, terminal-style layout, retro textures, and a floating footer.

== Installation ==

1. Upload the theme folder to /wp-content/themes/
2. Activate the theme in the WordPress admin
3. Go to Appearance > Customize to configure colors, CRT effects, LED status, and footer options
